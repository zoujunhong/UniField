# RocketCFD surface-pressure dataset

Raw files are stored under `/lustre/home/zdhs0017/data/RocketCFD/source`.
Per-case caches are stored under `~/zoujunhong/data/RocketCFD/cases/<case>/`
as `surface.npy` and `metadata.json`. This repository directory contains split
and manifest metadata only. `ROCKET_CFD_ROOT` can override the raw location.

## Published split contract

The five subsets are mutually exclusive at the **case** level:

| subset | geometry | AoA | purpose |
|---|---|---|---|
| `train` | train geometries | -8, -4, 0, 4, 8 | model fitting |
| `aoa_interpolation` | nine train probe geometries | -6, -2, 2, 6 | AoA interpolation |
| `aoa_extrapolation` | nine train probe geometries | -10, 10 | AoA extrapolation |
| `geometry_generalization` | g041--g048 | all 11 angles | unseen in-distribution families |
| `ood_geometry` | g049, g051, g052 | all 11 angles | deliberately OOD geometry |

`g020` and `g050` are quarantined from every subset because their canonical
geometry/CFD fields failed the orientation and numerical audit. They remain in
`manifests/excluded_cases.csv` for traceability.

The default `quality_policy="all_completed"` uses every completed case except
the two quarantined geometries, as requested. Convergence class remains in the
manifest so later experiments can select only `A_converged` and
`B_quasi_steady` with `quality_policy="usable"`:

| subset | default/all completed | optional usable only |
|---|---:|---:|
| train | 1938 | 1267 |
| AoA interpolation | 360 | 223 |
| AoA extrapolation | 180 | 136 |
| geometry generalization | 878 | 576 |
| OOD geometry | 330 | 237 |

The authoritative row-level manifest is `manifests/cases.csv`. `splits/*.txt`
and `splits_all_completed/*.txt` contain the default complete sets;
`splits_usable/*.txt` provides the optional converged/quasi-steady subset.

## Setup and cache generation

```bash
cd /data/home/zdhs0017/zoujunhong/code/whole_field
python -m dataset.cache.rocket_manifest
python -m dataset.cache.rocket_force_manifest
python -m dataset.RocketCFD --point-count 32768 --quality-policy all_completed --overwrite
```

The cache retains every native surface face when a case has at most 32768 valid
faces. Training redraws 8192 points per access with area-proportional sampling
and unbiased equal quadrature weights. `splits_force_consistent/train.txt` is
the audit list generated by requiring both full-face Cp integrals to agree with
OpenFOAM `forceCoeffs` within 0.02 for Cd and Cl; the force-supervised config
applies the same eligibility flag from `manifests/force_supervision.csv`.

To relocate the source or cache:

```bash
export ROCKET_CFD_ROOT=/path/to/rocket_cp_generalization_v1_draft
export ROCKET_CFD_CACHE_ROOT=/scratch/RocketCFD/cache
```

## Training and evaluation

Create a main experiment config using `RocketCFD_<Model>_<Scale>_SurfaceP_VolumeX.py`
and launch it with `python train.py --config <config>`. Evaluation split overrides
belong in the run config under `log/<main>/<variant>/config.py`. Historical auxiliary
experiment wrappers were retired during the 2026-11-18 cleanup.
